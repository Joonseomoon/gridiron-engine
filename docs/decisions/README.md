# Decisions

The project's design decisions, one file per milestone, appended in the order they were made. Each milestone's shared
prerequisite gets a section in its file before either developer starts; record anything that changes during
implementation in that section rather than rewriting history elsewhere. Keep decisions short, and when evidence changes,
add the new decision and mark the old one superseded.

| Milestone | File | Covers |
| --- | --- | --- |
| M0 | [M0.md](M0.md) | Platform and tooling, the V1 game rules, state transitions, and edge cases to test |
| M1 | [M1.md](M1.md) | Sampling assumptions, the command line, seeds, and built-in teams |
| M2 | [M2.md](M2.md) | Batch runs, seed policy, uncertainty statistics, convergence, and CSV export |
| M3 | [M3.md](M3.md) | Benchmark method, baselines, profiles, and parallel batches |
| M4 | [M4.md](M4.md) | Scenarios, candidate actions, policies, the clock and overtime, and decision comparisons |

Start a new file when a new milestone's shared prerequisite begins, and add it to this table.
